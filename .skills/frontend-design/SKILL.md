# Frontend Design Skill

Diseño visual de grado de producción que rechaza las estéticas de IA genéricas y plantillas prefabricadas a través de decisiones estéticas deliberadas.

## Pilares de Diseño
1. **Punto de Vista Intencional**:
   - Cada interfaz debe tener un carácter tangible alineado con el tema (para un acelerador: velocidad, transparencia, precisión cuántica, cristal y fluorescencia controlada).
   - Evitar combinaciones de fuentes predecibles o paletas estándar aburridas.
2. **Jerarquía Tipográfica con Peso Activo**:
   - Tipografía como elemento estructural.
   - Tamaños de encabezados con tracking negativo y números monoespaciados para telemetría precisa de bytes/segundo.
3. **Composición Espacial y Textura**:
   - Uso de bordes sutiles con translucidez (`rgba(255,255,255,0.08)`).
   - Fondos oscuros profundos (`#040407`) con degradados radiales etéreos de baja opacidad.
4. **Diseño de Movimiento (Motion Design)**:
   - Las animaciones deben reflejar estado real (ej. pulsos que representan paquetes de red fluyendo a través de los hilos de descarga).
