# High-End Visual Design

Criterios obligatorios para interfaces ultra-premium con estética de cristal:

1. **Jerarquía Visual y Espaciado (Golden Ratio)**:
   - Margen interior generoso (`padding: 1.5rem` a `2rem`).
   - Títulos con tracking negativo (`letter-spacing: -0.03em`).
2. **Glassmorphism Realista y Profundidad**:
   - `backdrop-filter: blur(24px) saturate(160%)`.
   - Borde de cristal sutil: `border: 1px solid rgba(255, 255, 255, 0.08)`.
   - Brillo interno biselado: `box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.12), 0 16px 40px rgba(0, 0, 0, 0.6)`.
3. **Fondos y Contraste**:
   - Fondos negros etéreos (`#040408`) evitando grises planos.
   - Acentos saturados brillantes usados quirúrgicamente en indicadores y micro-gráficos.
4. **Micro-interacciones**:
   - `transition: all 0.35s cubic-bezier(0.16, 1, 0.3, 1)`.
   - Hover con elevación suave `transform: translateY(-3px)`.
